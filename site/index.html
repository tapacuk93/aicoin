aicoin

A reverse proxy for AI provider APIs, and the coin priced off real usage.

aicoin‑proxy

Call any AI provider through one proxy — same request path, only the domain changes. An X-AI header picks the upstream (OpenAI, Anthropic, Google, Mistral, Cohere); the proxy holds the real paid key so you never need your own.

aicoin

A small signed blockchain: one primary node, optional read-only followers, a 1-coin-per-hour faucet, peer-to-peer transfers, and a price that decays smoothly with the real historical drop in AI inference cost.

Source, full docs, and the exact API/config reference: github.com/tapacuk93/aicoin
