How to use it

  1. Open the wallet and generate a new keypair — your address (public key) is what receives coins; your private key never leaves your browser.
  2. Claim free coins (up to 10 per wallet per hour, while the shared pool lasts — … left) so your balance is positive.
  3. Generate an API token from the wallet — a bearer credential you can use in scripts, no signing needed per call.
  4. Call any supported provider through the proxy, same request path as the real API, with two headers:
curl https://proxy.aicoin.oeaio.com/v1/chat/completions \
  -H "X-AI: openai" \
  -H "X-Api-Key: <token from the wallet>" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4","messages":[{"role":"user","content":"hi"}]}'

X-AI selects the upstream (see supported providers below); the proxy injects its own paid key so you never need your own. A 402 response means your aicoin balance ran out — claim more or buy some from another wallet.

What’s an aicoin?

1 aicoin is worth 1 paid AI call through proxy.aicoin.oeaio.com — the proxy holds the real paid provider key, so you spend aicoin instead of your own OpenAI/Anthropic/etc. key. The price above tracks a recency-weighted average of real recent AI spend, so it falls over time as inference gets cheaper.
