What's an AICoin?

1 AICoin always buys exactly 1 paid AI API call — a chat completion, an image generation, a text-to-speech clip — through apps.oeaio.com, our relay (aicoin-proxy) that holds its own paid provider credentials so you never need your own OpenAI/Anthropic/Google/etc. key. That 1-coin-per-call rate is fixed and enforced server-side, not a suggestion.

The "current market rate" above is a separate, informational number: a recency-weighted average of what a call has actually cost us in real provider spend recently. It's what we use to price coin packages fairly — it has no effect on the fixed 1-coin-per-call spend rate.

Getting AICoin

There are exactly two ways to acquire AICoin:

1. Buy it (in-app purchase)

Inside any app that supports AICoin, open the wallet/buy screen — the available coin packages and their App Store prices are set here on the server and can change at any time, so what you see in the app is always current. Payment is processed entirely by Apple through StoreKit; we never see your payment details. A successful purchase credits your wallet immediately.

2. Receive a transfer

Anyone can send AICoin to your wallet address, from the wallet page or from within a supporting app. There's no real-money rail on this path — it's a direct peer-to-peer balance transfer, the same way you'd hand someone cash.

A small free-coin faucet also exists for trying things out (up to 10 coins per wallet per hour, while the shared pool lasts — … left) — it's for onboarding, not a way to fund real usage.

Integrate AICoin (for developers)

Building an iOS/macOS app? The shared AICoinKit Swift package (in the aicoin repo, under ios-iap-redeem/) bundles wallet keys, StoreKit purchase → wallet-credit flow, transfer UI, and the provider-routing HTTP transport used by our own apps above — that's the fastest path in.

For any other client, or to call it directly, it's a plain HTTP relay: same request path as the real provider, one header to pick the upstream, an API token instead of your own provider key:

curl https://apps.oeaio.com/v1/chat/completions \
  -H "X-AI: openai" \
  -H "X-Api-Key: <token from the wallet>" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-4","messages":[{"role":"user","content":"hi"}]}'

A 402 response means the wallet's balance ran out — prompt the user to buy more or ask someone to send a transfer; never fall back to asking for their own provider key. Full API/config reference, the ledger's data model, and the IAP-redeem flow are documented in CONTRACT.md.

Source, full docs, and the exact API/config reference: github.com/tapacuk93/aicoin
